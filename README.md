# 굴러가유 ♿🗺️  
교통약자를 위한 휠체어 맞춤형 내비게이션 앱

---

## 📌 프로젝트 소개

굴러가유는 휠체어 사용자의 실제 이동 환경을 반영하여 **안전한 이동 경로를 제공하는 맞춤형 내비게이션 서비스**입니다.

기존 지도 서비스가 최단거리 중심으로 안내하는 반면, 굴러가유는 경사도, 턱, 보도 상태 등 휠체어 이동에 영향을 주는 요소를 반영해 경로를 추천합니다.

교통약자가 직접 겪는 이동 불편을 줄이기 위해 기획했습니다.

---

## 🚀 주요 기능

### 1. 휠체어 맞춤 경로 추천
- 일반 최단거리 대신 이동 가능 경로 우선 안내
- 위험 구간 회피

### 2. 위험 지역 표시
- 턱, 경사, 좁은 보행로 지도 위에 표시

### 3. 동행자 매칭 기능
- 휠체어 이용자와 동행자를 매칭해주는 기능
- 매칭 스케줄 관리
- 결제 시스템

### 4. 저상버스 시간표 제공
- 저상버스 시간표 API로 저상버스 운행 시간 제공
